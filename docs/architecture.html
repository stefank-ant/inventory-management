System Architecture

Factory Inventory Management System

A full-stack demo for inventory tracking, order management, demand forecasting, and spending analytics across factory warehouses. Single-page Vue frontend talking to a FastAPI backend over a JSON REST API — no database, all data served from in-memory mock files.

Vue 3 SPA FastAPI REST / JSON In-memory mock data No database
01 · Overview

System Architecture

Three layers: a Vue browser client, a stateless FastAPI service, and a read-only mock-data layer loaded from JSON. The client and server are separate origins; requests cross over HTTP with permissive CORS (development only).

03 · Behavior

Data Flow

A single request cycle, from a user changing a filter to a re-rendered chart. The four filters — warehouse, category, status, month — flow through as query params; the value all means "no filter".

1

User sets a filter

The FilterBar updates shared refs in the useFilters composable (warehouse · category · status · month).

2

View calls the API client

The active view reads the current filters and calls a method on src/api.js, e.g. api.getOrders(filters).

3

axios issues the request

GET http://localhost:8001/api/orders?warehouse=…&month=… — params equal to all are omitted before sending.

4

FastAPI filters in memory

apply_filters() matches warehouse/category/status case-insensitively; filter_by_month() accepts YYYY-MM or a quarter like Q1-2025. Source data is never mutated.

5

Pydantic validates & serializes

The route's response_model validates the shape and returns clean JSON.

6

Vue renders

The response lands in a ref; computed properties derive totals and chart series (custom inline SVG), and the view re-renders reactively.
